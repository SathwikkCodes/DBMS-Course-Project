# Examination Scheduling and Result Processing System

Database: project
MySQL user: root

This version explicitly demonstrates:
1. INSERTION - Add Student/Course/Exam/Room/Schedule/Result
2. UPDATION - Update existing Student/Course/Exam/Room/Schedule/Result
3. DELETION - Delete existing Student/Course/Exam/Room/Schedule/Result

Setup:
1. Open this folder in VS Code.
2. Open app.py.
3. Change YOUR_MYSQL_PASSWORD to your MySQL root password.
4. Run:
   python app.py
5. Open:
   http://127.0.0.1:5000

All Flask routes and MySQL connection code are kept in app.py.
